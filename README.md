# 冰箱食材菜谱

每天站在冰箱前不知道吃什么？勾上冰箱里已有的食材，马上知道能做什么菜、还缺什么、这周怎么吃。

在线演示：https://laomaiai.github.io/fridge-recipes/

## 这是什么

一个纯前端的 H5 工具，解决“冰箱里有什么就做什么”的决策问题：

- **食材匹配**：勾选冰箱里已有的食材，26 道家常菜按“缺得最少”排出来，食材齐全的排在最前面。
- **一周食谱**：按现有食材排一份 7 天午餐加晚餐的计划，优先用食材齐全的菜，其次用只差 1 样的菜，一周内尽量不重复。
- **买菜清单**：选中想做的菜或生成一周食谱后，缺失的食材自动汇总成一张清单，同名食材只出现一次，并注明每样要做几道菜。

## 确定性计算层：哪些是代码算的，哪些是大模型参与的

这个产品的核心是确定性规则代码，不靠大模型猜：

- **代码算的（全部核心逻辑）**：食材到菜谱的匹配。规则是：只统计非调料食材；一道菜的缺失数等于菜谱里非调料食材中用户没有的个数；排序按缺失数从少到多，缺失数相同按已有食材占比高者优先，再相同按耗时短者优先。一周食谱用确定性伪随机数生成，同一份种子每次生成同一份计划。买菜清单按缺失食材合并去重。
- **大模型参与的（目前没有）**：MVP 不接任何大模型，不花 API 钱。以后如果接大模型，只做菜谱文案润色，绝不生成用量和步骤；用量和步骤永远以结构化菜谱库为准。
- **菜谱库**：26 道常见家常菜，2-3 人份，用量与步骤按家庭常见做法人工编写，不是大模型生成的。

## 菜谱来源与免责声明

菜谱库的 26 道菜是家庭常见做法，用量按 2-3 人份编写，仅供参考；口味请按自家习惯调整。本产品不提供营养或医疗建议；如有过敏或特殊饮食需求，请以专业意见为准。

## 合规说明

本产品是做饭工具，不涉及股票、加密资产、资金托管或任何金融服务，不收集、不上传任何个人数据。

## 数据与隐私

全部计算在浏览器本地完成。勾选的食材、加入清单的菜、生成的计划只存在浏览器的 localStorage 里，不上传服务器，不做任何追踪。当前版本没有接入任何统计工具，用户数与收入数据均为零，等上线部署后再按真实后台数据记录，不编造数字。

## 本地运行（3 步）

```bash
npm install
npm run dev
```

打开浏览器访问终端显示的本地地址即可使用。

## 测试

```bash
npm test
```

Vitest 覆盖匹配逻辑：缺失数排序、常备调料不计入缺失、买菜清单合并去重、一周食谱的确定性与不重复、空冰箱时计划留空。

## 技术栈

React 19 + Vite + Tailwind CSS 4 + TypeScript，纯前端，零后端、零运行时依赖。
