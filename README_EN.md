# Fridge Recipes

You open the fridge every day and have no idea what to cook. Tick the ingredients you already have, and instantly see what you can cook, what you are missing, and what to eat this week.

Live demo: to be added after deployment

## What it is

A pure front-end H5 tool that solves the "cook with what is in the fridge" decision:

- **Ingredient matching**: tick the ingredients in your fridge, and 26 everyday home dishes are ranked by fewest missing ingredients, with fully covered dishes first.
- **Weekly meal plan**: a 7-day lunch-plus-dinner plan built from the ingredients you have, preferring fully covered dishes, then dishes missing exactly one ingredient, avoiding repeats within the week where possible.
- **Shopping list**: pick dishes you want to cook, or generate a weekly plan, and the missing ingredients are merged into one list. Each ingredient appears once, with how many dishes need it.

## Deterministic computation layer: what the code computes, what the model does

The core of this product is deterministic rule code, not model guessing:

- **Computed by code (all core logic)**: ingredient-to-recipe matching. The rules are: only non-seasoning ingredients count; a dish's missing count is the number of its non-seasoning ingredients you do not have; ranking is by missing count ascending, then by share of ingredients you already have, then by shorter cooking time. The weekly plan uses a seeded pseudo-random generator, so the same seed always produces the same plan. The shopping list merges duplicate missing ingredients.
- **Done by a large language model (none right now)**: the MVP connects to no language model and spends no API money. If a model is added later, it will only polish recipe copy, never generate quantities or steps; quantities and steps always come from the structured recipe library.
- **Recipe library**: 26 common home dishes, 2-3 servings each, with quantities and steps written by hand following everyday family cooking practice, not generated by a model.

## Recipe sources and disclaimer

The 26 recipes follow common family cooking practice, with quantities written for 2-3 servings, for reference only; adjust seasoning to your own taste. This product gives no nutrition or medical advice; if you have allergies or special dietary needs, consult a professional.

## Compliance

This product is a cooking tool. It involves no stocks, no crypto assets, no custody of funds, and no financial services. It collects and uploads no personal data.

## Data and privacy

All computation runs locally in the browser. Your ticked ingredients, picked dishes, and generated plans live only in the browser's localStorage. Nothing is uploaded to a server, and nothing is tracked. The current version has no analytics attached, so user and revenue numbers are zero; they will be recorded from real backend data after launch, never invented.

## Run locally (3 steps)

```bash
npm install
npm run dev
```

Open the local address shown in the terminal.

## Tests

```bash
npm test
```

Vitest covers the matching logic: ranking by missing count, seasonings excluded from missing counts, shopping-list merging and de-duplication, weekly-plan determinism and non-repetition, and an empty plan when the fridge is empty.

## Tech stack

React 19 + Vite + Tailwind CSS 4 + TypeScript, pure front-end, no back end, no runtime dependencies.
